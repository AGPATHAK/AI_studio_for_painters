# Compact Gemini Review Bundle

## Purpose

This compact bundle is a self-contained review package for Gemini. It reduces the larger review directory into a small number of consolidated documents suitable for attachment limits.

The review focus is multimodal workflow and UX critique for AI Painter Studio:
- critique surfaces,
- repaint workflows,
- multimodal interaction design,
- workflow sequencing,
- painter attention management,
- comparison systems,
- intervention scope visibility,
- and cognitively clean UX for AI-assisted painting critique.

Gemini should focus on multimodal workflow critique, not backend architecture, implementation details, or code review.

---

## Project Framing

AI Painter Studio is a painter-centered educational critique system.

The system exists to help painters:
- see visual structure more clearly,
- diagnose painting weaknesses,
- compare possible corrections,
- and repaint manually with better judgment.

The project rejects generic AI-art generation workflows. It is not trying to produce finished images automatically, imitate styles, beautify uploads, or turn critique into one-click improvement. AI outputs should function as teaching artifacts that support the painter's own decisions.

The central doctrine is:
1. upload a painting,
2. diagnose structural issues,
3. choose the right teaching workflow,
4. compare critique artifacts or controlled demonstrations,
5. repaint manually.

The repaint remains the center of learning.

## Requested Review Style

Please critique:
- where workflows are cognitively clean,
- where they are overloaded,
- how critique surfaces should be layered,
- which information should remain hidden until requested,
- how overlays, variants, value maps, and repaint guidance should be sequenced,
- how intervention scope should be shown,
- how tablet/iPad interactions should work,
- and how to preserve painter attention and agency.

Avoid recommendations that turn the product into a generic AI image generator.
