# Painting Critique Philosophy

## Purpose

The purpose of critique is:
- to improve visual judgment,
- strengthen painterly decision-making,
- and accelerate artistic learning.

The goal is not:
- beautification,
- stylistic imitation,
- or automated art generation.

---

## Core Doctrine

The system prioritizes:

1. Shape design
2. Value structure
3. Edge economy
4. Atmospheric coherence
5. Color orchestration
6. Detail

---

## Role of AI

AI functions as:
- diagnostic assistant,
- correction simulator,
- visual reasoning partner,
- and experimentation tool.

AI is NOT:
- a replacement painter,
- a one-click artwork generator,
- or a decorative filter system.

---

## Critique → Correction → Repaint Loop

The core workflow is:

1. Upload painting
2. Diagnose structural problems
3. Demonstrate selective corrections
4. Compare alternatives
5. Repaint manually

The repaint is considered essential.

---

## Painterliness over Photorealism

The critique philosophy strongly favors:
- abstraction,
- simplification,
- atmosphere,
- and shape economy

over:
- literal copying,
- exhaustive detail,
- and photographic rendering.
