# Glossary

## Purpose

This glossary defines recurring terms used across the AI Painter Studio knowledge base.

The goal is to keep critique language:
- consistent,
- painter-centered,
- pedagogically clear,
- and useful for future structured AI-assisted workflows.

Definitions are intentionally concise. They should guide critique and repaint decisions, not replace looking carefully at the painting.

---

## Atmospheric Greys

Muted mixtures that reduce color noise and help passages sit back in space.

Related concepts:
- chroma hierarchy,
- atmospheric simplification,
- restrained palette.

Usage boundary:
- Do not use atmospheric greys as a generic dulling strategy. They should support depth, unity, and focal hierarchy.

---

## Atmospheric Simplification

The use of omission, softening, value compression, and reduced detail to create air, depth, and visual calm.

Related concepts:
- shape economy,
- edge economy,
- chroma hierarchy,
- painterliness.

Usage boundary:
- This does not mean making the painting vague everywhere. It means simplifying secondary passages so the painting breathes.

---

## Chroma Hierarchy

The ordered control of saturation so color supports focus, depth, and atmosphere.

Related concepts:
- focal hierarchy,
- atmospheric greys,
- restrained palette,
- tonal cohesion.

Usage boundary:
- Avoid treating chroma as decoration. High chroma should be limited, intentional, and compositionally justified.

---

## Dominant Mass

A large, readable shape or value family that gives the painting structural authority.

Related concepts:
- value grouping,
- shadow architecture,
- shape economy,
- distance read.

Usage boundary:
- A dominant mass is not just a large object. It is a visual organization that remains legible when the painting is squinted at or viewed small.

---

## Edge Clutter

Excessive edge activity that makes too many forms compete for attention.

Related concepts:
- edge economy,
- edge equality,
- focal hierarchy,
- visual noise.

Usage boundary:
- Edge clutter is not the same as lively brushwork. Lively edges still have hierarchy and purpose.

---

## Edge Economy

Selective use of hard, soft, lost, and broken edges to control attention and atmosphere.

Related concepts:
- lost-and-found edge,
- focal hierarchy,
- atmospheric simplification,
- painterliness.

Usage boundary:
- Edge economy does not mean softening everything. Hard edges remain valuable when they clarify structure or strengthen the focal area.

---

## Demonstrative Critique

A critique mode that shows a possible correction or comparison so the painter can see the effect of a decision.

Related concepts:
- selective intervention,
- edit request,
- side-by-side comparison,
- repaintability.

Usage boundary:
- Demonstrative critique should remain a teaching artifact, not a replacement painting.

---

## Diagnostic Critique

A critique mode that identifies what is happening visually and names the root problem.

Related concepts:
- failure mode,
- value grouping,
- focal hierarchy,
- intervention priority.

Usage boundary:
- Diagnostic critique should not rush into prescription before the visual problem is clear.

---

## Edge Equality

The failure mode where too many edges have similar sharpness or visual importance.

Related concepts:
- edge clutter,
- focal hierarchy,
- visual noise,
- atmosphere.

Usage boundary:
- Use this term when the problem is sameness of edge emphasis, not simply the presence of many edges.

---

## Focal Hierarchy

The ordered control of contrast, edge sharpness, chroma, and detail density so the eye knows where to enter, pause, and move on.

Related concepts:
- value grouping,
- edge economy,
- chroma hierarchy,
- selective detail.

Usage boundary:
- Focal hierarchy is not only about the main subject. It is about the whole painting’s pattern of visual priority.

---

## Edit Request

A conceptual bridge between a critique issue and a controlled correction demonstration.

Related concepts:
- selected primitive,
- intervention scope,
- interpretability,
- selective intervention.

Usage boundary:
- An edit request should demonstrate one critique-linked lesson. It should not ask for general improvement.

---

## Fragmentation

A breakdown of visual unity caused by too many small, disconnected values, edges, colors, or marks.

Related concepts:
- visual noise,
- value grouping,
- dominant mass,
- shadow architecture.

Usage boundary:
- Fragmentation can occur even in a detailed painting. The issue is whether detail disrupts the major structure.

---

## High-Key Structure

A painting structure built from lighter, compressed value ranges while still preserving clarity and hierarchy.

Related concepts:
- tonal cohesion,
- atmospheric simplification,
- restrained contrast,
- Seago-like atmosphere.

Usage boundary:
- High-key does not mean weak value design. The relationships still need to read clearly.

---

## Intervention Scope

The intended breadth of a correction or teaching demonstration.

Related concepts:
- local intervention,
- regional intervention,
- compositional intervention,
- global study.

Usage boundary:
- Scope should be no larger than the visual problem requires.

---

## Lost-and-Found Edge

An edge that appears, disappears, and reappears as forms merge or separate.

Related concepts:
- edge economy,
- atmospheric simplification,
- painterliness,
- watercolor freshness.

Usage boundary:
- Lost-and-found edges should feel intentional. They are not the same as accidental mushiness.

---

## Painterliness

Visual authority created through selection, abstraction, brush-led decision-making, and restraint rather than literal transcription.

Related concepts:
- shape economy,
- atmospheric simplification,
- selective detail,
- repaint workflow.

Usage boundary:
- Painterliness is not looseness for its own sake. It depends on stronger choices, not fewer standards.

---

## Prescriptive Critique

A critique mode that names what the painter should try next.

Related concepts:
- repaint guidance,
- intervention priority,
- repaintability,
- selective intervention.

Usage boundary:
- Prescriptive critique should still leave room for painter judgment. It should not become a rigid recipe.

---

## Repaint Workflow

The learning loop of diagnosis, simplified planning, manual repainting, and comparison.

Related concepts:
- selective intervention,
- critique correction repaint,
- repaintability,
- visual judgment.

Usage boundary:
- A repaint is not treated as failure. It is often the clearest way to preserve freshness after structural insight emerges.

---

## Repaintability

The practical clarity of what a painter should do next in a new attempt.

Related concepts:
- repaint workflow,
- intervention priority,
- selective intervention,
- structural diagnosis.

Usage boundary:
- Repaintability is not the same as ease. A recommendation may be difficult, but it should be clear enough to guide the next painting.

---

## Selective Intervention

A local, interpretable correction that teaches the painter what to change and why.

Related concepts:
- repaint workflow,
- focal hierarchy,
- critique patterns,
- prompt primitives.

Usage boundary:
- Avoid using selective intervention to mean decorative retouching. The intervention should address a structural issue.

---

## Selected Primitive

The specific correction idea chosen to demonstrate a critique.

Related concepts:
- prompt primitive,
- edit request,
- selective intervention,
- failure mode.

Usage boundary:
- A selected primitive should address one clear visual lesson, not bundle multiple unrelated fixes.

---

## Teaching Critique

A critique mode that explains why a visual issue matters and turns it into a transferable principle.

Related concepts:
- painterly judgment,
- guiding question,
- repaintability,
- critique patterns.

Usage boundary:
- Teaching critique should explain visual cause and effect, not offer vague encouragement.

---

## Shadow Architecture

The design of connected dark or mid-dark passages as a structural pattern, rather than object-by-object shadow description.

Related concepts:
- value grouping,
- dominant mass,
- shape economy,
- landscape structure.

Usage boundary:
- Shadow architecture should support the painting’s design. It is not merely making shadows darker.

---

## Shape Economy

The reduction of forms into fewer, stronger, more readable shapes.

Related concepts:
- dominant mass,
- atmospheric simplification,
- painterliness,
- value grouping.

Usage boundary:
- Shape economy should preserve the essential character of the subject while removing unnecessary description.

---

## Tonal Cohesion

The sense that values belong to a unified visual world rather than competing as isolated decisions.

Related concepts:
- value grouping,
- high-key structure,
- atmospheric simplification,
- distance read.

Usage boundary:
- Tonal cohesion should not flatten the painting. It should clarify the relationships between masses.

---

## Value Grouping

The organization of lights, midtones, and darks into readable families or masses.

Related concepts:
- dominant mass,
- tonal cohesion,
- shadow architecture,
- focal hierarchy.

Usage boundary:
- Value grouping is not a formula for reducing every painting to three tones. It is a way of protecting readability.

---

## Visual Noise

Unnecessary activity that competes with the painting’s larger structure.

Related concepts:
- fragmentation,
- edge clutter,
- excessive chroma,
- detail addiction.

Usage boundary:
- Visual noise can come from value, edge, chroma, texture, or drawing decisions. Diagnose the source before correcting it.

---

## Workflow Selection

The decision process for choosing diagnostic critique, teaching critique, repaint guidance, overlay, value study, comparison, variant, or controlled demonstration.

Related concepts:
- critique type,
- failure mode,
- pedagogical intent,
- intervention scope.

Usage boundary:
- Workflow selection should favor the lightest artifact that helps the painter see and decide better.
