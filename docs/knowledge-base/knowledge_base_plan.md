# AI Painter Studio — Knowledge Base Plan

## Purpose

This document defines the canonical knowledge architecture for the AI Painter Studio critique ecosystem.

The goal is to transform accumulated critique discussions, workflows, and artistic doctrines into:
- reusable documentation,
- structured critique systems,
- prompt primitives,
- and future AI-readable knowledge assets.

---

# Core Principle

This phase is:
- conceptual,
- pedagogical,
- and architectural.

Implementation comes later.

---

# Planned Canonical Documents

## 1. painting_critique_philosophy.md
Core doctrines:
- role of critique
- role of AI
- critique → correction → repaint
- painterliness vs realism
- simplification philosophy
- anti-goals

---

## 2. visual_heuristics.md
Operational visual principles:
- value grouping

- focal contrast
- chroma control
- atmosphere
- simplification

---

## 3. common_failure_modes.md
Structured diagnostic handbook:
- symptoms
- causes

Pedagogical extraction from:
- Edward Wesson

- principles, not imitation.

# Guiding Heuristic

The system exists to help painters:
- see better,
- simplify better,
- and make stronger visual decisions.

Not to generate finished paintings automatically.
